# 判断の記録

レビューや検査で指摘されたが、直さないと決めたもの。範囲の中のものは指摘しなくてよい。範囲を超えるものは指摘する。

## D-001 診断の画面に出すエラーの要約（2026-11-06）
- 対象: 診断（doctor）の確認が失敗したときに画面に出す文
- 判断: 受け入れる（CodeQL の stack-trace-exposure）
- 範囲: 例外の型名と、メッセージの先頭 160 文字まで。traceback 全体・ファイルのパス・設定の値は画面に出さない（ログだけ）
- 理由: 診断の画面は、本人が自分の端末で原因を知るためのもの。型名と短い文がないと直し方がわからない
- 再判断: 診断の画面を本人以外が見られるようにするとき

## D-002 画面に返すファイルの場所の検査（2026-11-06）
- 対象: 受け取った場所のファイルを画面に返すところ
- 判断: 仕様どおり（CodeQL の path-injection）
- 範囲: artifact_file() で確かめ、その戻り値の場所（たどった先）だけを返す場合。artifact_file() を通さないもの、戻り値を使わないものは範囲外
- 理由: artifact_file() が、たどった先をセッションのフォルダの中・隠しファイル以外・画像と動画・普通のファイルに限っている
- 再判断: artifact_file() の検査を変えるとき
